# CoupleLink 1.0-r5 前台互动

绑定并登录后，首页可发送戳一下、震动、想你了、抱抱与响铃。对方在前台收到后显示中央大卡片；未绑定时同样的入口用于本机预览。

“我的”中可分别开关互动振动和对方响铃。振动默认开启，响铃默认关闭。关闭只影响本机反馈，仍显示互动卡片；系统触觉、静音、勿扰和音量设置也会影响结果。响铃是普通通知声音，最长约 1.8 秒，退出或进入后台时停止，不突破系统静音策略。

服务器先校验当前账号、设备和情侣关系，存储唯一 ID、动作和服务端有效期。普通互动有效 120 秒，响铃有效 30 秒；过期的互动不会领取。每账号互动最短间隔 1 秒，响铃间隔 15 秒。重试同一个 ID 不会创建第二条事件；发送结果未知时不会自动以新 ID 重发。

接收方所有设备中只有一台可领取某个事件，避免多个设备同时执行；领取后应用退出、网络断开或回执丢失时，事件不会重放，发送方可能只看到“已接收”。“已请求反馈”意味着已向操作系统请求，不代表硬件一定振动或发声。

在线事件通过已有 Centrifugo 通道触发拉取，前台每 2 秒另行检查。后台和进程退出时不保证实时到达；重新进入前台仅领取未过期事件。互动保存在自建数据库，不携带聊天正文。解绑或撤销会话后，新请求会重新校验并拒绝。

服务端接口：POST /interactions、GET /interactions、POST /interactions/claim、POST /interactions/result。当前未实现后台系统推送、手环通信、互动历史清理或自定义动作。
