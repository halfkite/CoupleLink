# CoupleLink 1.0-r10 · 安装与验收

## r10 重点回归

1. 覆盖安装 `CoupleLink-Android-1.0-r10.apk`；已有账号/绑定保持。已授权用户恢复会话后，无需再按后台开关，状态应自动显示后台接收运行中。
2. 首次授权/拒绝授权：一键授权与启动联动；拒绝后明确显示未开启，不反复申请、不阻塞其他按钮。在系统关闭通知后确认接收停止，重新打开通知并返回应用后自动恢复。
3. 点击“我的 → 测试震动”：应直接振动（通知用途 + 显式波形），即使手机“系统触感”关闭也应振动；打开“技术诊断”确认“系统触感”与渠道振动模式两项读数与实际一致。
4. 对方发送互动：前台应振动一次，桌面/锁屏应收到带振动的系统通知；不得出现一次互动重复振动两次。
5. 两个测试账号分别在前台、桌面和锁屏接收文字及互动；接收设置关闭和事件过期不触发主动反馈。
6. 对应类别被关闭/降级时显示真实状态，打开渠道设置后人工恢复；不得通过重建类别绕过用户设置。厂商横幅和锁屏开关按系统实际行为验收。

下方旧版本说明用于历史参考，后台接收以 r9 起的默认行为为准。

## 当前 Web 安卓版

安装 `CoupleLink-Android-1.0-r8.apk`，同签名覆盖安装，首次迁移重新登录。账号和服务端消息保留，旧 Flutter 待发消息不自动迁移。使用方法与边界以 [Web 安卓说明](WEB-ANDROID.md) 为准；下文 r7 清单保留作旧版参考，不代表新壳具备旧演示页面的所有功能。

1. 冷启动应进入首页；我的 → 填写服务器 → 测试连接 → 登录/注册。电脑热点地址为 `http://192.168.137.1:18080`。
2. 两个测试账号完成邀请和绑定，消息页双向发送；切断网络后发送文字，重启客户端、恢复网络后确认固定 ID 补发一次。通知授权关闭时仍应保存消息、显示红点并正常同步。
3. 在我的开启系统通知，测试顶部通知、震动与响铃；拒绝权限后应明确提示，其他按钮继续可用。系统设置中开启通知后再次测试。观察手机实际反馈，不能以“已请求”替代硬件验收。
4. 首页发送互动，对方前台显示中央卡片；关闭接收振动/响铃及开启系统勿扰后，确认反馈被抑制。互动不会离线无限排队。
5. 绑定后主动开启后台接收，确认常驻通知；切到桌面，另一账号发送消息和互动。省电、强制停止和系统时限均需分别验证，不承诺持续常驻。
6. 添加/测试/切换备用地址，确认换地址后要求重新登录，不能把旧令牌发往新服务器。主题、语言和开源许可均在我的页面。

## r7 旧 Flutter 清单

这是文字聊天、互动与系统通知测试版。账号、情侣关系和聊天连接自建服务器；用户可主动开启后台接收。距离、电量、纪念日、宠物及手环数据仍为示例；媒体、定位和手环同步未接入。请先用测试资料验收。

## Android

将 `CoupleLink-Android-1.0-r7.apk` 传到 Android 手机并通过系统安装器安装，支持同签名覆盖 r1 至 r6。最低 Android 7/API 24；建议 Android 8 及以上。系统通知需要用户授权；不请求位置、麦克风或相册权限。

1. 首页查看恋爱天数、互动、距离、宠物、见面倒计时与电量示例。
2. 长按首页卡片或点击右上角布置按钮，拖动顺序、隐藏与恢复卡片；重启确认设置仍在。
3. 已绑定时，点击互动会发给对方；对方前台应显示中央大卡片。未绑定时为本机预览。“本机振动测试”只作用于当前手机。点击“本机试听/本机振动测试”才请求此手机的反馈，不发给对方。系统静音、勿扰、通知音量为零时不播放提示音；触觉关闭或设备不支持时应给出明确结果。退出预览、返回或切后台后声音应停止。普通/静音/勿扰/无默认提示音分别真机验证，不能仅凭“已请求”断定硬件实际执行。
4. 地图为原创示意图。拖动底部面板，切换分享方式、精度、个人记录；切换定位状态并回放示例轨迹。没有真实位置采集。
5. 未登录时消息页仍为演示；登录且绑定后切换真实文字聊天。双方前台发送文字，确认接收内容一致，发送方从待发送变为已发送，再到已送达。已送达代表对方客户端已保存，不代表已读。关闭发送端网络发送数条，退出并重启 Android App，恢复网络后应各补发一次、保留草稿。浏览器因令牌仅在内存，刷新后须重新登录同一账号，队列仍可恢复。
6. 时光查看纪念日、相册布局与示例时间线。
7. 我的中切换三主题、中英文、减少动画，修改想你了的显示文案；重启确认偏好持久化。
8. 查看隐私、手环与诊断页面，未接入能力均应显示未连接或尚未接入。
9. 系统字体放大到 200%，检查窄屏、页面滚动和输入框；使用屏幕阅读器检查导航和按钮。
10. 我的 → 双人卡片，按 `服务器部署.md` 连接测试服务器。用两台设备分别注册，邀请绑定后刷新，确认昵称、恋爱起点和天数更新；解绑后另一端刷新清除关系，撤销设备后原令牌下一次请求被拒绝。浏览器刷新不会保留登录状态。未经用户配置服务器不会自动向外部地址连接。

## 小米手环 10

1. 使用 AstroBox 将 `CoupleLink-Band10-1.0-r7.rpk` 安装到手环。
2. 打开 CoupleLink，以底部上一页/下一页切换全部八页；页面内容超长时可纵向滚动。
3. 检查胶囊屏上下边缘、文字、按钮触摸与系统返回。
4. 互动需先确认，只显示演示反馈；不会向手机或对方发送请求，也不会实际响铃。
5. 设置页切换语言及粉/紫强调色，重新打开确认本地偏好缓存。
6. 检查重复启动、退出、重启，以及相同签名、递增 versionCode 的后续覆盖升级。

本轮没有接入手环后台常驻、系统振动、心率或双向通信。AstroBox 安装成功与日常同步连接是独立验收项。

## 聊天专项真机验收

通知、振动、红点、后台接收及多地址步骤见 `通知与服务器地址.md`。请在真机分别验证前台、后台、锁屏、网络断开、系统静音和勿扰；权限关闭时应明确提示。

账号页填写 `http://192.168.137.1:18080`，点击“测试连接”，无需先填账号密码。成功后注册或登录；失败时根据提示检查手机热点、服务器和防火墙。当前服务器监听热点地址，旧 Wi-Fi 地址须先切换服务监听。

1. 8 位纯数字密码应可注册和登录，7 位应拒绝；不要求大小写和特殊符号。旧长密码继续可用。
2. 连续快速发送、多次点击刷新，消息不可重复；另一设备登录同账号应加载相同历史。加载更早消息检查顺序。
3. 断网与重启恢复测试见第 5 项。队列达到容量限制时必须明确提示，不能丢弃未发送消息。
4. 让发送端断网并排入消息，由另一端解绑。恢复网络后原消息不可补发，旧关系聊天缓存、草稿和队列应清除，旧历史接口返回无权限。
5. 撤销某个设备后，其新消息请求应立即被拒绝；保留另一设备的会话。退出账号后旧缓存不应展示给新账号。
6. 将 App 放后台和锁屏：本轮不承诺后台送达；回到前台应补齐消息及回执，不将无通知显示为消息丢失。

## r5 真实互动真机验收

双方连接同一可互通服务器并绑定，App 均在前台。一方依次发送戳一下、震动、想你了和抱抱，另一方应显示明显卡片；在“我的”关闭互动振动后再次发送，卡片仍显示而不请求振动。响铃默认关闭；接收方开启后发送响铃，分别测试正常、静音、勿扰和零音量。发送端显示接收和反馈请求状态，并不代表硬件一定实际发声或振动。

让接收端离线，等待超过有效期后恢复前台，确认旧互动不会播放。连续点击应显示频率提示；解绑后旧关系不得继续发送。验证第二设备不会重复执行同一互动。手机在后台或进程退出时尚无推送，不能保证即时提醒；返回前台后只处理未过期互动。
