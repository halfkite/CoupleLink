# CoupleLink 1.0-r1 · 安装与验收

这是本地 UI 测试版。手机和手环中的 365 天、8.6km、电量、消息、纪念日和宠物均为固定示例，不代表真实设备状态。本轮不提供服务器登录、定位上传、真实聊天、远程响铃或手环数据同步。

## Android

将 `CoupleLink-Android-1.0-r1.apk` 传到 Android 手机并通过系统安装器安装。建议 Android 8 及以上；实际最低版本以 APK 元数据为准。本轮 UI 不需要位置、麦克风、相册或通知授权。

1. 首页查看恋爱天数、互动、距离、宠物、见面倒计时与电量示例。
2. 长按首页卡片或点击右上角布置按钮，拖动顺序、隐藏与恢复卡片；重启确认设置仍在。
3. 点击想你了、戳一下、抱抱显示本机预览；响铃显示接收方许可说明，不播放声音。
4. 地图为原创示意图。拖动底部面板，切换分享方式、精度、个人记录；切换定位状态并回放示例轨迹。没有真实位置采集。
5. 消息页输入内容后点击发送，仅加入本机演示会话；切换标签后内容及草稿保留，重启不承诺保留聊天演示。
6. 时光查看纪念日、相册布局与示例时间线。
7. 我的中切换三主题、中英文、减少动画，修改想你了的显示文案；重启确认偏好持久化。
8. 查看隐私、手环与诊断页面，未接入能力均应显示未连接或尚未接入。
9. 系统字体放大到 200%，检查窄屏、页面滚动和输入框；使用屏幕阅读器检查导航和按钮。

## 小米手环 10

1. 使用 AstroBox 将 `CoupleLink-Band10-1.0-r1.rpk` 安装到手环。
2. 打开 CoupleLink，以底部上一页/下一页切换全部八页；页面内容超长时可纵向滚动。
3. 检查胶囊屏上下边缘、文字、按钮触摸与系统返回。
4. 互动需先确认，只显示演示反馈；不会向手机或对方发送请求，也不会实际响铃。
5. 设置页切换语言及粉/紫强调色，重新打开确认本地偏好缓存。
6. 检查重复启动、退出、重启，以及相同签名、递增 versionCode 的后续覆盖升级。

本轮没有接入手环后台常驻、系统振动、心率或双向通信。AstroBox 安装成功与日常同步连接是独立验收项。
