# CoupleLink 1.0-r3 · 安装与验收

这是账号与互动测试版。手机账号、邀请绑定、设备会话可连接独立测试服务器，绑定后首页恋爱天数与昵称来自服务端；其他距离、电量、消息、纪念日与宠物，以及手环中的数据仍为示例。没有定位上传、真实聊天、远程响铃或手环数据同步。生产备份恢复尚待后续完成，请使用测试资料。

## Android

将 `CoupleLink-Android-1.0-r3.apk` 传到 Android 手机并通过系统安装器安装，支持同签名覆盖 r1/r2。最低 Android 7/API 24；建议 Android 8 及以上。本轮不需要位置、麦克风、相册或通知授权；增加了网络访问权限。

1. 首页查看恋爱天数、互动、距离、宠物、见面倒计时与电量示例。
2. 长按首页卡片或点击右上角布置按钮，拖动顺序、隐藏与恢复卡片；重启确认设置仍在。
3. 点击互动或“本机振动测试”，应在屏幕中央打开明显大卡片，状态持续显示。点击“本机试听/本机振动测试”才请求此手机的反馈，不发给对方。系统静音、勿扰、通知音量为零时不播放提示音；触觉关闭或设备不支持时应给出明确结果。退出预览、返回或切后台后声音应停止。普通/静音/勿扰/无默认提示音分别真机验证，不能仅凭“已请求”断定硬件实际执行。
4. 地图为原创示意图。拖动底部面板，切换分享方式、精度、个人记录；切换定位状态并回放示例轨迹。没有真实位置采集。
5. 消息页输入内容后点击发送，仅加入本机演示会话；切换标签后内容及草稿保留，重启不承诺保留聊天演示。
6. 时光查看纪念日、相册布局与示例时间线。
7. 我的中切换三主题、中英文、减少动画，修改想你了的显示文案；重启确认偏好持久化。
8. 查看隐私、手环与诊断页面，未接入能力均应显示未连接或尚未接入。
9. 系统字体放大到 200%，检查窄屏、页面滚动和输入框；使用屏幕阅读器检查导航和按钮。
10. 我的 → 双人卡片，按 `服务器部署.md` 连接测试服务器。用两台设备分别注册，邀请绑定后刷新，确认昵称、恋爱起点和天数更新；解绑后另一端刷新清除关系，撤销设备后原令牌下一次请求被拒绝。浏览器刷新不会保留登录状态。未经用户配置服务器不会自动向外部地址连接。

## 小米手环 10

1. 使用 AstroBox 将 `CoupleLink-Band10-1.0-r3.rpk` 安装到手环。
2. 打开 CoupleLink，以底部上一页/下一页切换全部八页；页面内容超长时可纵向滚动。
3. 检查胶囊屏上下边缘、文字、按钮触摸与系统返回。
4. 互动需先确认，只显示演示反馈；不会向手机或对方发送请求，也不会实际响铃。
5. 设置页切换语言及粉/紫强调色，重新打开确认本地偏好缓存。
6. 检查重复启动、退出、重启，以及相同签名、递增 versionCode 的后续覆盖升级。

本轮没有接入手环后台常驻、系统振动、心率或双向通信。AstroBox 安装成功与日常同步连接是独立验收项。
