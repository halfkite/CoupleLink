# CoupleLink 1.0-r3

- 取消服务器“最多两个账号”的硬限制和注册设置码要求；注册页只需账号、昵称和密码。保留密码哈希、频率控制、双人绑定和账号/关系隔离。
- 支持构建时显式选择局域网 HTTP 地址；Android 默认仍禁止明文，仅为指定 IP 生成例外，不包含子域或网段。外部服务器使用 HTTPS，API 不自动跟随跳转。
- 添加独立 Compose 本地启动脚本、真实健康检查、指定 IP 的本地子网防火墙规则和填写说明。
- 本次示例允许的电脑 Wi-Fi IP：10.74.205.253；r1/r2 交付文件保留。

# CoupleLink 1.0-r2

- 互动提示改为居中大卡片、暗色遮罩、明显图标和持续状态；首页增加本机振动测试入口。
- Android 本机提示音与系统触觉测试，遵守静音、勿扰及触觉设置；关闭页面和应用进入后台均停止声音。远程投递仍未接入。
- 私人 Go/PostgreSQL 服务：两账号注册、Argon2id 密码、独立设备会话、邀请绑定/解绑、版本校验、按用户同步事件。
- 手机新增账号与服务器页面、设备撤销；绑定后首页显示真实双方昵称、恋爱起点和天数；关系同步由用户手动刷新。
- 凭据只放安全存储；浏览器仅内存保存；外部服务器必须 HTTPS，HTTP 例外仅回环调试地址。
- 发布 APK、RPK 及 Windows/Linux 服务端，附 Compose 测试部署配置、验收与边界说明。
- 仍为隔离测试版：真实聊天、定位、宠物、远程响铃、手环桥接与生产备份恢复待后续开发。
- 修复独立服务端缺少 IANA 时区数据库导致有效绑定被拒绝的问题，嵌入时区资源并通过真实双客户端联调。

# CoupleLink 1.0-r1

首次 UI 测试交付。主版本按用户要求固定为 1.0，后续修订使用 r2、r3。

- Android：五栏主页面、三套主题、首页卡片排序与隐藏、基础互动动画预览。
- 消息：本地演示消息、草稿保留、图片与语音占位说明。
- 地图：原创示意图、可拖动面板、分享期限/精度/个人记录独立控件、定位状态预览、轨迹回放。
- 时光：纪念日、见面倒计时、相册预览与时间线。
- 偏好：中英文、文案覆盖、减少动画、本地保存，隐私与设备诊断入口。
- 手环：八页 Vela 快应用、同包名/同证书的 Release RPK、语言与强调色缓存。
- 构建：版本契约、语言 Key 检查、APK/RPK 打包与 SHA-256 清单。
- 修正：小屏页头横向约束、地图 Material 绘制层、大字体纪念日与聊天头部布局；随包中文字体保证离线渲染。

业务服务器、实时消息、定位、健康数据和 Wearable SDK 桥接属于后续阶段，本轮仅显示演示状态。
